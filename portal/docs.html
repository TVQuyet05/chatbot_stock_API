Tài liệu API

Chào mừng bạn đến với tài liệu hướng dẫn tích hợp StockLaw API. Dịch vụ này cho phép bạn truy vấn kiến thức pháp luật chứng khoán thông qua mô hình ngôn ngữ lớn (LLM) kết hợp với cơ sở dữ liệu pháp luật chính thống.

Xác thực (Authentication)

API sử dụng OAuth2 Client Credentials Flow. Bạn cần đăng ký thiết bị/ứng dụng để nhận client_id và client_secret.

Endpoint lấy Token
POST /auth/token

POST /api/v1/ask

Truy vấn kiến thức pháp luật chứng khoán.

Request Body

{
  "question": "Điều kiện niêm yết cổ phiếu?",
  "top_k": 5
}

Response

{
  "answer": "Để niêm yết cổ phiếu, doanh nghiệp cần đáp ứng...",
  "sources": [
    {
      "document_name": "Luật Chứng khoán 2019",
      "article_number": "15",
      "similarity_score": 0.85
    }
  ],
  "processing_time": 1.2
}
